How it works

The interesting part is what the app doesn't do.

Nothing ticks

The database is never written to on a timer. Each dividend stores the parameters of a straight line — amount, window, rate — and the figure is recomputed from the clock every frame.

Close it for a week

Reopen and it shows the right number. Nothing is being counted, so there is no count to lose.

Works offline

Your device already has the parameters. It doesn't need the server to keep counting.

Never floating point

Money is BigDecimal end to end, and crosses the network as text — a JSON number would be parsed into a double and quietly destroy a per-second rate.

What the numbers actually mean

A growing figure is not money you have received, and this app is careful never to suggest otherwise.

FigureWhat it is
ExpectedShares × declared dividend per share. An estimate.
AccumulatingProgress towards that estimate. Rounded down, so it is never overstated.
ReceivedOnly settled payments. The one figure that counts as income.

Where the data comes from

Yahoo Finance. It reports some things and not others, and the app distinguishes between them.

FieldSource
Share priceReported
Ex-dividend dateReported
Dividend per shareReported
Payment frequencyInferred from the spacing of past ex-dates
Payment dateEstimated — Yahoo does not publish it
Record dateUnavailable — stored empty rather than guessed

Yield is a trailing twelve months of dividends actually paid, not one declaration multiplied out — real companies vary their payouts, and special dividends exist.

Before you install

This is a personal project, not a financial product.

Prices and dividend history come from an undocumented Yahoo Finance endpoint with no service guarantee. Payment dates are estimates. Nothing here is investment advice, and no figure in this app should be relied on for a financial decision.

The Windows build is unsigned, so SmartScreen will warn you. The Android build is sideloaded for the same reason.
