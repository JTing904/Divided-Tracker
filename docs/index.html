How it works

Nothing is counting.

The interesting part is what the app doesn't do. No timer increments a total, which is precisely why the number is always right.

01

A line, not a tally

Each dividend stores four parameters — amount, window, rate, start. The figure is recomputed from the clock every frame.

02

Close it for a week

Reopen and it shows the right number. Nothing was being counted, so there is no count to lose.

03

Works offline

Your device already holds the parameters. It doesn't need the server to keep going.

04

Never floating point

Money is BigDecimal throughout and crosses the network as text — a JSON number becomes a double and quietly destroys a per-second rate.

Honesty

Three numbers, never confused.

A growing figure is not money you have received, and this app never implies otherwise.

ExpectedShares × declared dividend per share. An estimate.
AccumulatingProgress toward that estimate. Rounded down, so it is never overstated.
ReceivedSettled payments only. The one figure that counts as income.
Data

What is reported, and what is not.

Prices and dividend history come from Yahoo Finance. It publishes some fields and not others, and the app keeps the difference visible rather than papering over it.

Before you install

The honest caveats.

A personal project, not a financial product.

Data comes from an undocumented endpoint with no service guarantee. Payment dates are estimates. Prices are delayed 15–30 minutes, so this is not a trading tool.

Nothing here is investment advice, and no figure in this app should be relied on for a financial decision.

Neither build is code-signed, so Windows SmartScreen and Android will both warn you before installing.
